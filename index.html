🌱 NodeMCU 스마트 팜 시뮬레이터

고1 과학탐구실험 · 피지컬 컴퓨팅 프로젝트

35:00

🎯 과제

하루 8시간 빛 · 16시간 어둠을 주고, 습도가 40% 이하로 떨어지면 70%가 될 때까지 물을 뿌리는 스마트 팜을 만든다. 현재 습도는 디스플레이에 표시되어야 한다.

제한 시간 35분. 위의 ⏱ 시작을 누르면 타이머가 돌아간다. 시간이 다 되거나 완료·제출을 누르면 자동으로 채점되어 저장된다.

📘 NodeMCU 초기 세팅 설명서

실물로 할 때 거치는 과정이다. 시뮬레이터에서는 1~4단계가 이미 끝나 있다고 보고 5단계부터 시작한다.

1. NodeMCU가 무엇인가

ESP8266 칩을 얹은 마이크로컨트롤러 보드. 교과서의 '마이크로컨트롤러 보드'에 해당한다. Wi-Fi가 내장되어 있고, USB 케이블 하나로 전원 공급과 코드 업로드를 함께 한다.

항목값
동작 전압3.3 V (5 V 부품 직결 주의)
디지털 핀D0 ~ D8
아날로그 핀A0 한 개 (0 ~ 1023)
기본 I2C 핀SDA = D2, SCL = D1

2. 드라이버 설치

보드의 USB-시리얼 칩에 맞는 드라이버를 PC에 설치한다. 칩이 CP2102면 실리콘랩스 드라이버, CH340이면 WCH 드라이버. 설치 후 장치 관리자(또는 시스템 정보)에서 COM 포트가 보이면 성공.

3. Arduino IDE에 보드 추가

  1. 파일 → 환경설정 → '추가적인 보드 매니저 URLs'에 아래 주소를 넣는다.
    https://arduino.esp8266.com/stable/package_esp8266com_index.json
  2. 툴 → 보드 → 보드 매니저 → esp8266 검색 → 설치
  3. 툴 → 보드 → NodeMCU 1.0 (ESP-12E Module) 선택
  4. 툴 → 포트 → 연결된 COM 포트 선택

4. 라이브러리 설치

스케치 → 라이브러리 포함하기 → 라이브러리 관리에서 두 개를 설치한다.

  • DHT sensor library (Adafruit) — 온습도 센서용. 같이 뜨는 Adafruit Unified Sensor도 함께 설치
  • LiquidCrystal I2C — I2C 디스플레이용

5. 배선 후 업로드

  1. 전원을 뺀 상태에서 부품을 연결한다. (전원이 들어온 채로 선을 꽂으면 부품이 상한다)
  2. USB를 연결하고 → 버튼(업로드)을 누른다.
  3. 시리얼 모니터를 115200 bps로 열어 값이 찍히는지 확인한다.

⚠️ 자주 하는 실수

  • GND를 빠뜨림 — 전기는 돌아올 길이 있어야 흐른다. 모든 부품의 GND를 보드 GND에 연결한다.
  • D3, D4에 부품을 물리고 업로드 실패 — 이 두 핀은 부팅에 관여한다. 가능하면 D5~D7을 쓴다.
  • 모터를 보드에 직결 — 전류가 커서 보드가 재부팅된다. 실물에서는 릴레이나 모터 드라이버를 거친다. 시뮬레이터에서는 펌프 모듈이 그 역할을 이미 포함하고 있다.

🪜 단계별 힌트

1단계 · 구조 그리기
피지컬 컴퓨팅은 입력 → 처리 → 출력의 되먹임 고리다. 무엇이 입력이고 무엇이 출력인지 먼저 적어 본다. (⑤ 점검표 탭의 서술 칸)
2단계 · 전원과 접지
모든 부품의 VCC를 3V3에, GND를 GND에 연결한다. LED의 (−)도 GND다. 이것부터 하면 나머지가 쉬워진다.
3단계 · 신호선 연결
DHT22의 DATA는 아무 디지털 핀이나(D5 권장). 디스플레이는 SDA → D2, SCL → D1로 정해져 있다. 펌프의 IN과 LED의 (+)도 각각 디지털 핀에 연결한다. 어느 핀에 꽂았는지 꼭 기억한다.
4단계 · 뼈대 코드
③ 코드 탭의 뼈대 불러오기를 누르면 핀 번호와 setup()까지 들어 있는 틀이 나온다. TODO 부분만 채우면 된다.
5단계 · 센서 읽기
float h = dht.readHumidity(); 로 습도를 읽는다. 우선 Serial.println(h)로 값이 들어오는지부터 확인한다.
6단계 · 디스플레이
lcd.setCursor(0,0); lcd.print("Humidity: "); lcd.print(h);
숫자가 바뀔 때 잔상이 남으면 lcd.clear()를 먼저 부른다.
7단계 · 급수 제어 (히스테리시스)
if (h < 40) 물 켜기 만 쓰면 40% 근처에서 계속 깜빡인다. 켜는 기준과 끄는 기준을 다르게 둔다. 켜짐 상태를 기억하는 변수 bool pumpOn을 하나 만들어, h <= 40이면 켜고, h >= 70이면 끈다.
8단계 · 광주기 8/16
millis()는 켜진 뒤 지난 시간(ms)이다. 하루는 86400000 ms, 8시간은 28800000 ms.
unsigned long t = millis() % 86400000UL; 로 '오늘 몇 시인지'를 구하고, t < 28800000UL 이면 LED를 켠다.
9단계 · 돌려 보기
④ 시뮬레이션 탭에서 ▶ 실행. 배속을 올려 하루가 지나가는 것을 확인한다. 습도가 40까지 떨어졌다가 70까지 차오르는 장면과, 빛이 8시간 뒤 꺼지는 장면을 모두 봐야 점수가 들어온다.
연결 방법 — 부품 쪽 단자를 누르고, 이어서 NodeMCU 쪽 핀을 누르면 선이 생긴다. 선을 누르면 지워진다.
