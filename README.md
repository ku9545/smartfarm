# NodeMCU 스마트 팜 시뮬레이터

고1 과학탐구실험 피지컬 컴퓨팅 수행평가용 웹앱. 아이패드 사파리에서 바로 돌아감.

## 파일

| 파일 | 쓰임 |
|---|---|
| `index.html` | 학생용. 로그인 → 설명서 → 배선 → 코드 → 시뮬레이션 → 채점 |
| `teacher.html` | 교사용. 반별 점수표, 학생별 코드·배선·서술 확인, CSV 내려받기 |

두 파일 모두 바깥 라이브러리를 쓰지 않는 단일 HTML임. 빌드 과정 없음.

## GitHub Pages 올리기

1. 새 저장소를 만들고 두 파일을 최상위에 올림.
2. 저장소 Settings → Pages → Source 를 `Deploy from a branch`, 분기는 `main`, 폴더는 `/ (root)` 로 지정.
3. 1~2분 뒤 주소가 생김.
   - 학생: `https://<계정>.github.io/<저장소>/`
   - 교사: `https://<계정>.github.io/<저장소>/teacher.html`

Netlify Drop 에 폴더째 끌어다 놓아도 똑같이 동작함.

## 서버

Supabase 프로젝트 `science-project-tracker` (ap-northeast-2) 안의 `sf_` 로 시작하는 표만 사용.
탐구 워크시트(`ws_`)와 진행판 표는 건드리지 않음.

- `sf_students` — 학번·이름·비밀번호 해시(bcrypt). 10번 틀리면 10분 잠김
- `sf_submissions` — 점수, 항목별 결과, 배선, 코드, 시뮬 기록, 소요 시간
- `sf_settings` — 교사 키 해시

모든 표는 RLS 가 켜져 있고 정책이 하나도 없음. 브라우저에서 표를 직접 조회할 수 없고,
오직 `SECURITY DEFINER` 함수(RPC)로만 접근함. 교사 함수는 키를, 학생 함수는 비밀번호를 검사함.

**교사 키 초기값은 `smartfarm2026`. 첫 수업 전에 교사 화면에서 반드시 바꿀 것.**

## 수업 진행

1. 학생에게 주소를 알려 주고 '처음이에요' 로 반·학번·이름·비밀번호 등록.
2. ① 탭에서 과제와 설명서를 읽게 함.
3. 준비되면 상단 **⏱ 시작**. 35분 타이머가 돌아감.
4. 시간이 끝나거나 **완료·제출** 을 누르면 자동 채점 후 서버에 저장.
5. 교사 화면에서 실시간으로 점수와 제출물 확인. 수업 끝에 CSV 로 내려받아 보관.

재제출이 가능하며, 교사 화면에는 **최고점 기록**이 보이고 제출 횟수가 함께 표시됨.

## 채점

40점 만점, 항목 하나를 만족하지 못할 때마다 5점 감점. 다섯 항목이므로 점수는 **15 ~ 40점**.

각 항목은 학생 화면에 **물음**으로 그대로 제시됨.

| # | 평가 항목 | 학생에게 던지는 물음 | 인정 조건 |
|---|---|---|---|
| 1 | 피지컬 컴퓨팅의 큰 구조를 설명할 수 있음 | 이 장치가 세상에서 무엇을 받아들이고, 세상에 어떻게 되돌려 주는가? | 구조 확인 문항 4개 중 3개 이상 정답 |
| 2 | 코딩을 통해 프로세싱 할 수 있음 | 코드가 센서 값을 읽어, 그 값에 따라 장치를 실제로 움직이는가? | 오류 없이 돌면서 센서 값을 읽고, 그 결과로 펌프나 생장등이 켜졌다 꺼짐 |
| 3 | 센서를 연결해 온도 혹은 습도를 측정함 | 센서가 제대로 물려 있고 실제 측정값이 들어오는가? | VCC·GND·DATA 배선 + 측정 함수가 값을 받아옴 |
| 4 | 액츄에이터를 통해 결과를 디스플레이 함 | 값이 숫자로 뜨고, 값이 바뀌면 화면도 따라 바뀌는가? | 디스플레이 배선 + 숫자 표시 + 내용이 갱신됨 |
| 5 | 온습도의 특정 조건에 따라 반응하는 장치를 구현함 | 과제가 정한 조건대로 반응하는가? | 급수(40%↓ 작동, 70%↑ 정지)와 광주기(8시간 점등)가 모두 관측됨 |

**2번은 코드의 문법이나 생김새를 보지 않음.** 학생이 AI에게 코드를 받아 와도 상관없고,
받아 온 코드가 자기가 꽂은 핀과 맞물려 실제로 장치를 움직이는지만 봄.
2·3·4·5번 모두 코드를 읽어서 매기지 않고, 시뮬레이션에서 그 일이 일어나는지로 매김.
배속을 '1초 = 1시간' 이상으로 올리면 하루가 24초 만에 지나감.

채점이 실제로 갈리는 모습:

| 제출 상태 | 점수 |
|---|---|
| 과제대로 완성 | 40 |
| 디스플레이에 고정 문구만 띄움 | 35 (4번 탈락) |
| 조건이 과제와 다름 (60/65, 빛 12시간) | 35 (5번 탈락) |
| 값만 읽고 아무것도 움직이지 않음 | 30 (2·5번 탈락) |
| 코드는 완벽한데 센서 선을 안 꽂음 | 20 |
| 문법 오류로 실행되지 않음 | 20 |
| 아무것도 하지 않음 | 15 |

### 구조 확인 문항

1번 항목은 서술이 아니라 객관식 네 문항으로 확인함. 묻는 것은 다음 네 가지임.

1. 마이크로컨트롤러가 바깥 세상을 **인식하는 통로**는 무엇인가 (센서의 역할)
2. 읽은 값이 안에서 **처리된다**는 것은 무슨 뜻인가 (기준과 견주어 판단하기)
3. 세상에 **반응하는 방식**끼리 묶인 것은 (펌프·생장등·디스플레이)
4. 출력이 환경을 바꾸고 그 변화가 다시 입력이 되는 짜임은 무엇인가 (되먹임 고리)

몇 번이든 고쳐 고를 수 있고, 고른 답과 정오는 교사 화면 상세와 CSV 에 남음.
자기 말로 쓰는 **구조 서술 칸**은 그대로 두되 점수에는 넣지 않음 — 세특 서술 재료로만 씀.

## 시뮬레이터가 알아듣는 코드

아두이노 C++ 의 부분 집합을 직접 해석함.

- 자료형: `int` `float` `bool` `long` `unsigned long` `const`
- 제어문: `if/else` `for` `while` `break` `continue` `return`, 매개변수 있는 사용자 함수
- 전처리기: `#define`, `#include`(무시)
- 내장 함수: `pinMode` `digitalWrite` `digitalRead` `analogWrite` `analogRead`
  `delay` `millis` `map` `constrain` `abs` `random` `isnan`
- 객체: `Serial.begin/print/println`, `dht.begin/readHumidity/readTemperature`,
  `lcd.init/begin/backlight/clear/home/setCursor/print`
- 상수: `HIGH` `LOW` `OUTPUT` `INPUT` `D0`~`D8` `A0` `DHT22`

배선이 틀리면 센서는 `nan` 을 돌려주고 디스플레이는 켜지지 않음. 코드와 하드웨어를 함께 맞춰야 함.

## 부품

| 부품 | 모델 · 규격 | 동작 전압 | 보드 연결 |
|---|---|---|---|
| 마이크로컨트롤러 | NodeMCU V3 (ESP8266 ESP-12E, CP2102 또는 CH340) | USB 5 V → 내부 3.3 V | — |
| 온습도 센서 | DHT22 (AM2302) | 3.3 ~ 6 V | VCC → `3V3` 또는 `VIN`, DATA → 디지털 핀 |
| 디스플레이 | 1602 캐릭터 LCD + PCF8574 I2C 백팩 (주소 0x27) | 5 V | VCC → `VIN`, SDA → `D2`, SCL → `D1` |
| 물뿜개 | DC 3~6 V 미니 수중 펌프 + 1채널 릴레이 모듈 (SRD-05VDC-SL-C) | 5 V | VCC → `VIN`, IN → 디지털 핀 |
| 생장등 | 식물 생장용 LED 모듈 (적색 660 nm + 청색 450 nm) | 5 V | (+) → 디지털 핀, (−) → `GND` |

### VCC는 어디에 꽂나

부품의 `VCC`는 핀 이름이 아니라 '전원이 들어오는 자리'라는 뜻임. 보드 쪽 전원 핀은 두 개.

- `3V3` — 보드가 만들어 내는 3.3 V. DHT22처럼 전류를 적게 쓰는 센서에 알맞음.
  여러 부품을 한꺼번에 물리면 레귤레이터가 못 버텨 보드가 재부팅됨
- `VIN` — USB에서 온 5 V가 그대로 나오는 핀. 디스플레이·릴레이·LED는 여기에 꽂아야 함.
  3V3에 물리면 LCD 글자가 흐리고 릴레이가 붙지 않음

**시뮬레이터는 `3V3`과 `VIN` 둘 다 전원으로 인정함.** GND만은 반드시 연결해야 함.

## 시뮬레이션 물리 모형

- 습도: 시간당 5%씩 떨어짐(생장등이 켜져 있으면 9%). 펌프가 돌면 시간당 60%씩 오름
- 온도: 생장등 켜짐 26°C, 꺼짐 21°C 로 수렴
- 식물 건강: 습도 30~95% 구간에서 회복, 벗어나면 시듦
